Mention Telegram 分頁連接隱私權政策

更新日期：2026 年 10 月 29 日｜適用版本：瀏覽器擴充功能 0.1.1

1. 維護者與適用範圍

本擴充功能由【hankais】提供。公開聯絡信箱：【hankais903@gmail.com】。
本政策說明「Mention Telegram 分頁連接」瀏覽器擴充功能的資料處理。Mention Windows 桌面工具及 Telegram 網頁版是另外的程式；本擴充功能不提供 Telegram 登入、訊息偵測或待辦儲存。

2. 功能與使用者選擇

在使用者主動啟用並配對後，擴充功能接收同台電腦 Mention 工具的 Telegram Web 開啟指令，優先重用原有 Telegram 分頁，或在沒有適用分頁時建立一個。使用者可指定優先分頁，並可隨時關閉本機連接或移除擴充功能。

3. 處理哪些資料

本機配對碼：使用者從 Mention 複製並貼上，用於向本機工具驗證連接。保存在 chrome.storage.local，並透過本機 WebSocket 傳送給 Mention。
Telegram 分頁資料：僅為選擇與重用分頁，讀取符合 https://web.telegram.org/ 的分頁 URL、分頁 ID、是否作用中、最近存取排序資訊與視窗 ID。只保留使用者指定的優先分頁 ID，不建立瀏覽紀錄資料庫。
目的訊息網址：從本機工具接收 Telegram Web URL，可能包含群組、訊息編號或帳號參數。僅用於導航，不另行建立歷史紀錄。
執行狀態：在本機保存最近連接狀態；與工具交換命令 ID、成功／失敗確認與連線保活訊息。

4. 不處理哪些資料

本擴充功能不讀取 Telegram 訊息正文、對話清單的頁面內容、附件、Cookie、Telegram 登入密碼、驗證碼或 Telegram session。它不透過 content script 擷取頁面，也不蒐集鍵盤輸入紀錄、廣告識別資料、付款資料或其他網站的瀏覽內容。擴充功能不會要求填入 Telegram 電話或 API 資料。

5. 資料流向與分享

擴充功能只與同一台電腦的 ws://127.0.0.1:18764 通訊，不將配對資料或使用紀錄傳送給開發者的伺服器，也未整合分析、廣告或追蹤 SDK。資料不出售、不用於廣告、不建立使用者檔案、不用於信用或貸款決策。
開啟 Telegram 網頁版時，瀏覽器會正常與 Telegram 網站通訊；該網站的資料處理由 Telegram 的政策及瀏覽器設定管理，不在本擴充功能控制範圍內。
本機配對連接使用 loopback WebSocket，並非 TLS 網際網路連線。配對碼保存在瀏覽器本機儲存，本擴充功能不額外加密該儲存。請勿分享配對碼或瀏覽器使用者資料夾。

6. 保存期間與刪除方式

配對碼、優先分頁 ID 及連接狀態會在本機保存至被新值取代、使用者清除擴充功能儲存資料或移除擴充功能為止。暫存的目標 URL、分頁排序與命令結果只在執行期間使用。
停用擴充功能或在 Mention 取消「啟用原分頁連接」可停止連接，但停用本身不等於刪除本機資料。移除擴充功能後，瀏覽器通常會移除其本機儲存；Mention 的本機設定、登入工作階段與待辦不會因此刪除，需另由桌面工具或作業系統管理。

7. 權限用途

storage：保存本機配對設定、優先分頁 ID 與狀態。
alarms：在工具暫時未啟動或瀏覽器背景工作恢復時重新嘗試連接。
https://web.telegram.org/*：查找、更新與聚焦 Telegram 網頁分頁。
http://127.0.0.1/*：授權與本機 Mention 連接；實際只使用固定埠 18764。

8. Limited Use 承諾

本擴充功能對 Chrome API 所提供資訊的使用遵循 Chrome 線上應用程式商店使用者資料政策，包括 Limited Use 限制。資料僅用於上述明確揭露的分頁連接功能，不用於與該功能無關的用途。
